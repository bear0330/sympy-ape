# sympy-ape Java

Java 17 sources generated by APEBind 0.4.2 from `sympy.com`. The portable
executable is stored as a JAR resource and extracted on first use.

```java
import apebind.generated.sympy_ape.SympyAPEBinding;

var value = SympyAPEBinding.integrate(
    SympyAPEBinding.IntegrateParameters.builder()
        .expr("sin(x)")
        .build());
```

`./scripts/test.sh` compiles the package with `javac` and checks `version`,
`integrate`, `diff`, and `subs`. Regenerating this package with APEBind
replaces `src/` and keeps `tests/`.
