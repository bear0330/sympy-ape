# sympy-ape Node.js

ESM package generated by APEBind 0.4.2 from `sympy.com`. It evaluates SymPy
expressions without a host Python installation.

```js
import { integrate, diff } from 'sympy-ape';

console.log(await integrate({ expr: 'sin(x)' }));
console.log(await diff({ expr: '-x**2', order: 1 }));
```

`./scripts/test.sh` calls `version`, `integrate`, `diff`, `solve`, and `subs`.
Regenerating this package with APEBind replaces `src/` and keeps `tests/`.
